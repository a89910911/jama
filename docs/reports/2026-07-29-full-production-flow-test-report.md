## 5. 非阻断观察项

1. 主前端 JS 包约 1,243.5 KiB（gzip 413.67 KiB），构建给出大包告警。当前不影响功能，但建议后续按路由拆包。
2. `example_drama/` 是被 Git 忽略的可选示例资源，当前工作区没有该目录，因此 Electron Builder 给出可选资源缺失告警；示例入口会自动隐藏，不影响新建、导入和生产链路。
3. 分镜数量预估与最终安全拆分数量可能差异较大。本样例预估约 3 条，实际因旁白/对白时长约束拆为 15 条。结果正确，但建议后续优化 UI 估算说明。
4. 提示词优化模型曾生成与角色参考图不完全一致的文字描述，但真实图片/视频仍由参考图锁定并保持了主要人物特征。这属于模型质量波动，应通过生产监控持续观察。
